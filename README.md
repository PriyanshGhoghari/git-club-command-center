# Git Club Command Center

A dashboard for Git Club CHARUSAT to review events, members, projects, and club activity. It includes Admin, Event Lead, and Member preview views.

## Live site

https://git-club-command-center-charusat.vercel.app

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The app is a React, TypeScript, and Vite single page application. Demo changes are saved in the browser.
